# 📋 Project Roadmap

This document outlines the vision and planned evolution of the Aprendiendo Español project.

## 🎯 Current Phase: Foundation (Q1 2026)

**Status:** ✅ In Progress

- [x] Repository structure and documentation
- [x] Contribution guidelines
- [x] Lesson template and organization
- [ ] Initial beginner lessons (targeting 10-15 lessons)
- [ ] Core grammar references
- [ ] Essential vocabulary lists
- [ ] Import content from existing gists

### Priority Lessons to Create

1. Greetings and Introductions ✅
2. Alphabet and Pronunciation
3. Numbers (0-100)
4. Subject Pronouns

**Goal:** Build comprehensive lesson library

- [ ] Complete beginner level (A1-A2) - 30+ lessons

- [ ] Add audio pronunciation guides
- [ ] Create vocabulary flashcard sets
- [ ] Develop practice exercise answer keys
- [ ] Community contributions and reviews

## 💻 Phase 3: Interactive Tools (Q3 2026)

**Goal:** Build learning applications

### Web Applications

- [ ] Static website with searchable lesson index
- [ ] Interactive flashcard system
- [ ] Verb conjugation practice tool
- [ ] Vocabulary quiz generator
- [ ] Progress tracking dashboard

**Technology Stack (Proposed):**

- Framework: Next.js or Astro (static site generation)
- Styling: Tailwind CSS
- Deployment: Vercel or GitHub Pages
- Content: Markdown-based, version-controlled

### Mobile/Desktop Apps

- [ ] Flashcard mobile app
- [ ] Daily practice reminder app
- [ ] Offline lesson access
- [ ] Spaced repetition system

**Technology Stack (Proposed):**

- React Native or Flutter (cross-platform)
- Local storage for offline access
- Sync with web platform
