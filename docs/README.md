# 📚 Lesson Library

Welcome to the lesson library! Here you'll find structured Spanish learning materials organized by proficiency level.

## 🎓 Learning Paths

### [Beginner (A1-A2)](./beginner)

Start here if you're new to Spanish!

- Basic greetings and introductions
- Present tense verbs
- Essential vocabulary (numbers, colors, family, food)
- Simple sentence structures
- Basic questions and answers

### [Intermediate (B1-B2)](./intermediate)

Ready to go deeper?

- Past tenses (preterite, imperfect)
- Future and conditional
- Subjunctive mood introduction
- Complex sentence structures
- Conversational fluency

### [Advanced (C1-C2)](./advanced)

Refine your mastery!

- Advanced subjunctive usage
- Idiomatic expressions
- Regional variations
- Formal vs informal registers
- Literary and professional Spanish

### [Resources](./resources)

Reference materials for all levels

- Grammar quick references
- Verb conjugation tables
- Vocabulary lists by topic
- Pronunciation guides
- Cultural notes

## 📖 How to Use These Lessons

1. **Assess your level**: Start with content that challenges but doesn't overwhelm
2. **Follow the structure**: Each lesson builds on previous concepts
3. **Practice actively**: Do the exercises, speak out loud, write examples
4. **Review regularly**: Repetition is key to language learning
5. **Have fun**: Language learning is a journey, not a destination!

## 🗺️ Lesson Numbering

Lessons are organized by topic rather than strict sequence. Feel free to jump around based on your interests and needs!

## 💡 Tips for Success

- **Daily practice**: Even 15 minutes daily beats 2 hours once a week
- **Speak out loud**: Don't just read—pronounce everything
- **Make mistakes**: They're essential for learning
- **Use it in context**: Try to use new words in real situations
- **Be patient**: Language acquisition takes time
