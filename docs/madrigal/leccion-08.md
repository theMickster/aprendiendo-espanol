## Category XIV — English **-tion** → Spanish **-ción**

You already know this powerful pattern:

**TION = CIÓN**

| English      | Español         |
| ------------ | --------------- |
| invitation   | la invitación   |
| preparation  | la preparación  |
| co-operation | la cooperación  |
| imitation    | la imitación    |
| continuation | la continuación |
| recitation   | la recitación   |

## From noun to past-tense verb (quick method)

Take the noun in **-ción**, remove **-ación / -ición** to get the stem, then add:

- **-é** for **yo**
- **-ó** for **usted / él / ella**

In Spain, you will also use **-aste / -iste** constantly for **tú**.

| Stem     | Yo (**-é**) | Tú (**-aste/-iste**) | Usted/él/ella (**-ó**) |
| :------- | :---------: | :------------------: | :--------------------: |
| invit-   |   invité    |      invitaste       |         invitó         |
| prepar-  |   preparé   |      preparaste      |        preparó         |
| cooper-  |   cooperé   |      cooperaste      |        cooperó         |
| imit-    |    imité    |       imitaste       |         imitó          |
| continu- |  continué   |     continuaste      |        continuó        |
| recit-   |   recité    |      recitaste       |         recitó         |

## Forming questions in the past

For formal **usted** questions:

- **¿Votó usted?**
- **¿Continuó usted?**
- **¿Cooperó usted?**

With names or titles, Spanish often places the subject after the verb:

- **¿Votó Roberto?**
- **¿Entró el doctor?**
