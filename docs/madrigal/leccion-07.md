## Category XII — English **-ce** → Spanish **-cia**

You can convert many English words ending in **-ce** into Spanish by changing **-ce** to
**-cia**.

**CE = CIA**

_the distance_ = **la distancia**

Most of these words are feminine in Spanish and use **la** / **una**.

|                   |                  |                  |                    |
| :---------------- | :--------------- | :--------------- | :----------------- |
| la abstinencia    | la conciencia    | la efervescencia | la importancia     |
| la abundancia     | la conferencia   | la elegancia     | la independencia   |
| la adolescencia   | la consecuencia  | la elocuencia    | la indiferencia    |
| Alicia            | la conveniencia  | la esencia       | la inocencia       |
| la ambulancia     | la decadencia    | la evidencia     | la insignificancia |
| la arrogancia     | la desobediencia | la excelencia    | la insistencia     |
| la asistencia     | la diferencia    | la experiencia   | la inteligencia    |
| la ausencia       | la difidencia    | Francia          | la justicia        |
| la benevolencia   | la diligencia    | la frecuencia    | la paciencia       |
| la ciencia        | la distancia     | la gracia        | la persistencia    |
| la circunferencia | la eficiencia    | la impaciencia   | la preferencia     |
| la circunstancia  | la emergencia    | la incidencia    | la tolerancia      |
| la coherencia     | la competencia   | la influencia    | la violencia       |
| la coincidencia   | la permanencia   |                  |                    |

## Category XIII — English **-cy** → Spanish **-cia**

You can convert many English words ending in **-cy** into Spanish by changing **-cy** to
**-cia**.

**CY = CIA**

_the agency_ = **la agencia**

These are also generally feminine and use **la** / **una**.

|                 |               |                |
| :-------------- | :------------ | :------------- |
| la aristocracia | la eficacia   | la eficiencia  |
| la burocracia   | la farmacia   | la deficiencia |
| la democracia   | la agencia    | la suficiencia |
| la diplomacia   | la emergencia |                |
| la discrepancia | la tendencia  |                |
| la decencia     | la urgencia   |                |

## Another common spelling pattern: **SP = ESP**

When an English word starts with **s + consonant**, Spanish usually adds an **e** before that
cluster.

| Español      | English             |
| ------------ | ------------------- |
| especial     | special             |
| espiritual   | spiritual           |
| esplendor    | splendor            |
| estable      | stable              |
| estabilidad  | stability           |
| especialista | specialist          |
| España       | Spain               |
| esposo       | husband, spouse     |
| esposa       | wife                |
| estación     | station             |
| estudiante   | student             |
| estúpido     | stupid              |
| especialidad | specialty           |
| el español   | Spanish (language)  |
| español      | Spanish (adjective) |

## Sentence forming drills

Use the key verbs below to build many combinations:
**estudiar, notar, expresar, aceptar, comparar, explicar**.

When you need it, use a small connector column to make the sentence complete:
**de**, **del**, **sobre**, **con**, **algo**.

### Exercise in Translation

Translate the following sentences into Spanish. Use the vocabulary and drill tables above.

1. I study the importance of patience every day.
2. Do you (tú) notice something important this morning?
3. We express the difference between Spain and France in class.
4. Did you (usted) accept the evidence of the case yesterday?
5. They studied Alicia’s experience in the office.
6. I compared the democracy of Spain this afternoon.
7. Do you all (ustedes) explain the agency during the meeting?
8. We did not study the importance of patience at home.
9. Did you (tú) express something important this afternoon?
10. They noticed the difference in the station.
