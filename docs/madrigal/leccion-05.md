## Words ending in -ry

You can convert many English words that end in **-ry** into Spanish words by changing the **-ry** to **-rio**.

**Example:** _the canary_ = **el canario**

|                         |                       |                         |               |
| :---------------------: | :-------------------: | :---------------------: | :-----------: |
|       adversario        |    extraordinario     |        monetario        |  secretario   |
|       aniversario       |     fragmentario      | necesario _(necessary)_ |  secundario   |
|         canario         | glosario _(glossary)_ |         notario         |   seminario   |
| comentario _(comment)_  |      hereditario      |        obituario        |   solitario   |
|        contrario        |      imaginario       |        ordinario        |    sumario    |
|        culinario        |      incendiario      |      parlamentario      | suplementario |
| diario _(diary, daily)_ |     involuntario      |        primario         |  temporario   |
|       diccionario       |      itinerario       |      reaccionario       |  tributario   |
|       dignitario        |      laboratorio      |     revolucionario      |  veterinario  |
|      disciplinario      |       literario       |         rosario         |  visionario   |
|        emisario         |      mercenario       |         salario         |  voluntario   |

Some of the above words may be made feminine simply by changing the final **-o** to **-a**.

**Example:** el secretario (masc.), la secretaria (fem.)

## Words ending in -em, -am, or -om

You can convert some English words that end in **-em**, **-am**, or **-om** into Spanish words by adding the letter **-a**.

All of these words are masculine:

|               |                            |             |
| :-----------: | :------------------------: | :---------: |
|  el programa  |        el diagrama         | el sistema  |
| el telegrama  |        el epigrama         |  el poema   |
| el cablegrama |        el monograma        | el problema |
|  el emblema   | el idioma _(the language)_ |             |

Some words that end in **-ma** are alike in English and Spanish: el drama, el panorama, el dilema.

**Note:** "El clima" means "the climate."

## Words to remember

| Español     | English                                  |
| ----------- | ---------------------------------------- |
| un amigo    | a friend                                 |
| una amiga   | a (female) friend                        |
| la fiesta   | the party                                |
| esta mañana | this morning                             |
| esta tarde  | this afternoon                           |
| el cine     | the movies                               |
| el teatro   | the theatre                              |
| a           | to                                       |
| a la        | to the (fem.)                            |
| al          | to the (masc.) — contraction of "a + el" |
| al cine     | to the movies                            |
| esta noche  | tonight (this night)                     |
| Roberto     | Robert                                   |
| su mamá     | your mother                              |
| mi mamá     | my mother                                |
| su papá     | your father                              |
| mi papá     | my father                                |
| a la fiesta | to the party                             |

**Note:** "Mamá" and "papá" are informal words like _"mom"_ and _"dad."_ "Madre" _(mother)_ and "padre" _(father)_ are more formal.

### Exercise in Translation

Translate the following sentences into Spanish. Write out each sentence in Spanish, using the columns above as a guide. After you have written out all the sentences check with the correct translations below this exercise.

1. I invited my mother to the movies.
2. I invited your mother to the party.
3. Did you (tú) invite Roberto to the theatre?
4. I visited your mother this morning.
5. I visited Robert this afternoon.
6. Did you (usted) visit my father this afternoon?
7. Did you (tú) visit my mother this morning?
8. Did you (usted) visit Robert tonight?
9. Did you (usted) invite Robert to the party?
10. Did you (tú) invite a friend to the class?
11. Did you (usted) invite your mother to the movies?
12. Did you (tú) invite your father to the theatre?
