## Words ending in -or

Words ending in **-or** are often identical in Spanish and English (e.g. _the doctor_ = el doctor).

|           |           |                      |                  |
| --------- | --------- | -------------------- | ---------------- |
| actor     | agresor   | ardor                | autor _(author)_ |
| candor    | censor    | coautor _(coauthor)_ | color            |
| conductor | director  | doctor               | editor           |
| error     | exterior  | favor                | fervor           |
| furor     | honor     | horror               | humor            |
| inferior  | inspector | instructor           | interior         |
| motor     | opresor   | pastor               | profesor         |
| protector | reflector | rumor                | sector           |
| superior  | tenor     | tractor              | tumor            |
| tutor     | valor     | vapor _(steam)_      | vigor            |

> **Note:** Spanish words that end in **-or** are stressed on the last syllable (e.g. doc-**TOR**). The letter **r** is trilled in Spanish.

### English -tor → Spanish -dor

Some English words ending in **-tor** become **-dor** in Spanish (e.g. _the senator_ = el senador).

|            |             |           |              |
| ---------- | ----------- | --------- | ------------ |
| acelerador | colaborador | creador   | dictador     |
| educador   | elevador    | generador | investigador |
| operador   | orador      | radiador  | ventilador   |
