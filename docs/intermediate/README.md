# 🌿 Intermediate Lessons (B1-B2)

Ready to take your Spanish to the next level!

## 🎯 Level Description

**B1 Level (Threshold):** Handle most everyday situations, express opinions and plans
**B2 Level (Vantage):** Interact with native speakers naturally, understand complex texts

You're in the right place if:

- You can hold basic conversations
- You know present tense well
- You're ready for past and future tenses
- You want to express more complex ideas

## 🗺️ Suggested Learning Path

Work through the sections in order -- each builds on the last:

- **Sections 1-2** lay the foundation with past/future tenses and core grammar structures
- **Section 3** expands your ability to describe and compare things
- **Section 4** covers reflexive verbs, which appear constantly in everyday Spanish
- **Section 5** is the biggest section -- new tenses and moods that unlock complex expression
- **Section 6** focuses on Spain-specific usage and natural communication
- **Section 7** tackles advanced B2 topics once you're comfortable with the rest

Within each section, lessons are ordered by dependency. However, some lessons can be done independently:

- Lessons 07 (Gustar), 08 (Tener que), and 09 (Hace + Time) are independent of each other
- Lesson 16 (Negative Constructions) can be done anytime after Section 2
- Lesson 19 (Vosotros) can be started anytime if you need it for Spain-specific contexts

## 💡 Study Tips for Intermediate Learners

- **Consume content**: Watch shows, read articles, listen to podcasts
- **Speak regularly**: Find language exchange partners
- **Grammar in context**: Learn tenses through stories, not just tables
- **Keep a journal**: Write daily entries in Spanish
- **Push boundaries**: Try content slightly above your level
- **Focus on fluency**: Perfection comes later
- **Review beginner lessons**: Revisit fundamentals when intermediate topics feel shaky
- **Practice in pairs**: Many of these topics contrast with each other (ser/estar, preterite/imperfect) -- study them together
