# 📢 Commands (El Imperativo)

## Tell, Ask, Instruct -- Getting Things Done in Spanish!

**⏱️ Study Time: 15 minutes**
**🎯 Goal: Form affirmative and negative commands for tú, vosotros, usted, and ustedes -- and know where to put pronouns!**

---

## Overview

Commands (the imperative mood) are how you tell, ask, or instruct someone to do something. You use them constantly: "Come here!", "Sit down!", "Don't worry!", "Tell me!" In Spanish, the form of the command changes depending on WHO you're talking to and WHETHER the command is affirmative or negative.

---

## 1️⃣ Affirmative TÚ Commands

For most verbs, the affirmative tú command is the same as the él/ella present indicative form:

| Infinitive | Tú command  | Reasoning                |
| ---------- | ----------- | ------------------------ |
| hablar     | **habla**   | él habla → tú: habla     |
| comer      | **come**    | él come → tú: come       |
| escribir   | **escribe** | él escribe → tú: escribe |
| pensar     | **piensa**  | él piensa → tú: piensa   |
| volver     | **vuelve**  | él vuelve → tú: vuelve   |

### The 8 Irregular TÚ Commands

These must be memorized:

| Infinitive | Tú command | Memory tip                   |
| ---------- | ---------- | ---------------------------- |
| decir      | **di**     | **di**me = tell me           |
| hacer      | **haz**    | **haz**lo = do it            |
| ir         | **ve**     | **ve** = go                  |
| poner      | **pon**    | **pon**lo aquí = put it here |
| salir      | **sal**    | **sal** de aquí = get out    |
| ser        | **sé**     | **sé** bueno = be good       |
| tener      | **ten**    | **ten** cuidado = be careful |
| venir      | **ven**    | **ven** aquí = come here     |

1. **¡Ven aquí!** (Come here!)
2. **¡Haz los deberes!** (Do the homework!)
3. **¡Di la verdad!** (Tell the truth!)
4. **¡Pon la mesa!** (Set the table!)

---

## 2️⃣ Affirmative VOSOTROS Commands

Replace the **-r** of the infinitive with **-d**:

| Infinitive | Vosotros command |
| ---------- | ---------------- |
| hablar     | **hablad**       |
| comer      | **comed**        |
| vivir      | **vivid**        |
| venir      | **venid**        |
| hacer      | **haced**        |

5. **¡Venid aquí, niños!** (Come here, kids!)
6. **¡Comed la verdura!** (Eat the vegetables!)
7. **¡Haced los deberes!** (Do the homework!)

### Reflexive Vosotros Commands: Drop the -d

When a vosotros command is reflexive, drop the **-d** before adding **-os**:

| Infinitive | Expected          | Actual        |
| ---------- | ----------------- | ------------- |
| sentarse   | ~~sentad + os~~   | **sentaos**   |
| levantarse | ~~levantad + os~~ | **levantaos** |
| irse       | (exception)       | **idos**      |

8. **¡Sentaos a la mesa!** (Sit down at the table!)
9. **¡Levantaos, que es tarde!** (Get up, it's late!)

**Note:** "idos" (go away) is the exception -- it keeps the -d.

---

## 3️⃣ USTED / USTEDES Commands

These use the **present subjunctive** forms (see [Lesson 17](17-present-subjunctive.md)):

| Infinitive | Usted     | Ustedes    |
| ---------- | --------- | ---------- |
| hablar     | **hable** | **hablen** |
| comer      | **coma**  | **coman**  |
| vivir      | **viva**  | **vivan**  |
| venir      | **venga** | **vengan** |
| hacer      | **haga**  | **hagan**  |
| ir         | **vaya**  | **vayan**  |
| ser        | **sea**   | **sean**   |
| tener      | **tenga** | **tengan** |

10. **Venga por aquí, por favor** (Come this way, please)
11. **Hagan la tarea para mañana** (Do the assignment for tomorrow)
12. **Vaya al final del pasillo** (Go to the end of the hallway)

---

## 4️⃣ Negative Commands: NO + Subjunctive (ALL Persons!)

For negative commands, ALL forms use **no** + present subjunctive. This is where it gets simpler -- one rule covers everything:

### Negative TÚ commands

| Affirmative (tú) | Negative (tú)   |
| ---------------- | --------------- |
| habla            | **no hables**   |
| come             | **no comas**    |
| escribe          | **no escribas** |
| ven              | **no vengas**   |
| haz              | **no hagas**    |
| di               | **no digas**    |
| ve               | **no vayas**    |

### Negative VOSOTROS commands

| Affirmative | Negative         |
| ----------- | ---------------- |
| hablad      | **no habléis**   |
| comed       | **no comáis**    |
| escribid    | **no escribáis** |
| venid       | **no vengáis**   |

### Negative USTED / USTEDES commands

Just add **no** before the same subjunctive form:

| Affirmative (usted) | Negative (usted) |
| ------------------- | ---------------- |
| hable               | **no hable**     |
| coma                | **no coma**      |
| venga               | **no venga**     |

| Affirmative (ustedes) | Negative (ustedes) |
| --------------------- | ------------------ |
| hablen                | **no hablen**      |
| coman                 | **no coman**       |
| vengan                | **no vengan**      |

13. **¡No te preocupes!** (Don't worry!)
14. **¡No me digas!** (You don't say! / Don't tell me!)
15. **¡No hagáis ruido!** (Don't make noise!)

---

## 5️⃣ Pronoun Placement with Commands

This is crucial and trips people up. The rule is simple:

### Affirmative commands: pronouns ATTACH to the end

Add a written accent to maintain the original stress:

16. **¡Dime!** (Tell me!) -- decir + me
17. **¡Dímelo!** (Tell it to me!) -- decir + me + lo
18. **¡Siéntate!** (Sit down!) -- sentar + te
19. **¡Cómpralo!** (Buy it!) -- comprar + lo
20. **¡Escríbele!** (Write to him/her!) -- escribir + le

### Negative commands: pronouns go BEFORE the verb

21. **¡No me digas!** (Don't tell me!)
22. **¡No te sientes ahí!** (Don't sit there!)
23. **¡No lo compres!** (Don't buy it!)
24. **¡No me lo digas!** (Don't tell it to me!)

| Affirmative    | Negative              |
| -------------- | --------------------- |
| **Dímelo**     | **No me lo digas**    |
| **Siéntate**   | **No te sientes**     |
| **Cómpralo**   | **No lo compres**     |
| **Hazlo**      | **No lo hagas**       |
| **Ponlo aquí** | **No lo pongas aquí** |

## 💡 Quick Summary

| Person   | Affirmative                      | Negative         |
| -------- | -------------------------------- | ---------------- |
| Tú       | él/ella present (+ 8 irregulars) | no + subjunctive |
| Vosotros | infinitive -r → -d               | no + subjunctive |
| Usted    | subjunctive                      | no + subjunctive |
| Ustedes  | subjunctive                      | no + subjunctive |

**Pronouns:** Attached after affirmative commands, before negative commands.
