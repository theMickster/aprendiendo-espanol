# 🇪🇸 Aprendiendo Español

> La familia Shawsky está aprendiendo español en Valencia. ¡Únete a la aventura!

## 👋 Welcome | Bienvenidos

This is a family-driven project documenting our journey learning Spanish while living in Valencia, Spain. We're building a collection of lessons, resources, and tools to help ourselves—and anyone else—learn Spanish in a practical, engaging way.

**Everyone is welcome to join, contribute, and learn with us!**

## 🎯 Project Goals

- Create accessible Spanish learning materials for all levels
- Document real-world language experiences from Valencia
- Build interactive tools and apps to support learning
- Foster a community of Spanish learners

## 📚 Repository Structure

```
aprendiendo-espanol/
├── docs/               # Lesson materials and guides
│   ├── beginner/      # A1-A2 level content

└── README.md          # You are here!
```

## 🚀 Getting Started

### For Learners

1. Browse the [docs folder](./docs) to find lessons at your level
2. Start with [beginner materials](./docs/beginner) if you're just starting out
3. Check out [resources](./docs/resources) for grammar guides and vocabulary lists

### For Contributors

We welcome contributions of all kinds:

- **Lesson content**: Share your Spanish learning materials
- **Corrections**: Help us fix errors and improve clarity
- **Translations**: Add parallel translations for better understanding
- **Ideas**: Suggest new topics or improvements via [Issues](../../issues)
- **Code**: (Coming soon) Help build learning apps and tools

See [CONTRIBUTING.md](./CONTRIBUTING.md) for detailed guidelines.

### For Developers

Setting up the development environment:

- **First time**: Run `npm install` to install Prettier and Git hooks
- **Auto-formatting**: Files are automatically formatted when you commit
- **Manual format**: Run `npm run format` to format all files

See [DEVELOPMENT.md](./DEVELOPMENT.md) for complete setup instructions.
